<section id="intro">
  <h1 class="text-3xl font-bold text-gray-100 mb-4">Meet 1q: Less Googling, More Doing - My CLI Sidekick!</h1>
  <p>Hey everyone, gather 'round the virtual terminal! <strong>I've been tinkering away on a little CLI tool that I think is pretty darn useful, and I'm excited to share it!</strong> It's called <strong>1q</strong> (short for 1Query), and it's designed to do one thing really well: turn your everyday English requests into shell commands or code snippets. No more awkwardly phrasing Google searches for that one specific `awk` or `find` command – <em>I</em> built this to be way faster. Let's check it out!</p>
</section>

<section id="whats-the-problem">
  <h2 class="text-3xl font-bold text-gray-100 mb-4">The Endless Command Search? I Built a Solution!</h2>
  <p>Okay, let's be honest. How many times have you been deep in thought, needing to do something on the command line – like "find all text files modified yesterday in this directory and its subdirectories" – and your brain just... stalls? You *know* there's a command, maybe involving `find` or `grep` or some arcane flags, but remembering the exact syntax? Ugh. So you open a browser, type something vague into Google, sift through Stack Overflow... sound familiar? <em>I</em> found myself doing this constantly, and it felt like such a workflow killer.</p>
  <p>That's exactly why <em>I</em> built <strong>1q</strong>. It's like having a command-line expert sitting next to you, powered by AI (specifically Google's Gemini). You just type what you want to do in plain English, and 1q gives you the command.</p>
  <p><strong>"Wait, <em>you</em> made an AI command generator? Does it actually work?"</strong></p>
  <p>Yup, <em>I</em> did! And yeah, it works surprisingly well! <em>I</em> focused on making it simple and direct. Ask a question, get a command. Sometimes it needs a little refinement, but that's built-in too! The goal was to keep me (and hopefully you!) in the terminal, focused on the task, not on searching syntax.</p>
</section>

<section id="key-features">
  <h2 class="text-3xl font-bold text-gray-100 mb-4">Key Features: Speak Your Mind, Get Your Command!</h2>
  <p>So what makes 1q tick, and why did <em>I</em> build it this way?</p>
  <ul class="list-disc list-inside mb-4">
    <li><strong>Natural Language Input:</strong> Just type what you need! <code>1q find files larger than 10MB modified last week</code>. <em>I</em> wanted it to feel intuitive, like talking to an assistant.</li>
    <li><strong>Gemini Powered:</strong> It uses Google's Gemini AI (specifically `gemini-1.5-flash`) to understand your request and generate accurate commands or code snippets. <em>I</em> picked Gemini for its strong language understanding capabilities.</li>
    <li><strong>Smart Output (TUI & Inline):</strong> Simple query? Get just the command, ready to pipe or use (`inline` mode). More complex query with explanations? Get a nice Textual User Interface (`tui` mode) breaking down the command, explanation, and install steps. <em>I</em> designed the `auto` mode to pick the best view for you.</li>
    <li><strong>Interactive Workflow:</strong> Got the command? Great! You can instantly:
        <ul>
          <li><strong>Execute (`x`):</strong> Run it right away.</li>
          <li><strong>Modify (`m`):</strong> Tweak it before running.</li>
          <li><strong>Copy (`c`):</strong> Copy it to your clipboard.</li>
          <li><strong>Refine (`r`):</strong> Ask for a change (e.g., "make it recursive"). 1q remembers the context!</li>
        </ul>
      <em>I</em> wanted a tight feedback loop right in the terminal.</li>
    <li><strong>Context-Aware Refinement:</strong> Didn't get it perfect first try? Just hit 'r' and tell 1q what to change. It remembers the previous query and response, making refinements easy. This was crucial for me – iteration without starting over.</li>
    <li><strong>Cross-Platform:</strong> Built with Python, it runs on Linux, macOS, and Windows. <em>I</em> made sure the prompts to Gemini include OS info for better platform-specific commands!</li>
  </ul>
</section>

<section id="tech-simplified">
  <h2 class="text-3xl font-bold text-gray-100 mb-4">Under the Hood (Simplified Tech - From Me to You!)</h2>
  <p>Let's peek under the hood, keeping it simple. <em>I</em> built 1q primarily with <strong>Python</strong> because it's fantastic for scripting and has great libraries. It's like the Swiss Army knife of programming languages – perfect for a tool like this.</p>
  <p>The AI magic comes from the <strong>Google Generative AI SDK</strong> (<code>google-generativeai</code>). This is the official library <em>I</em> used to talk to the Gemini API. Think of it as the phone line connecting 1q to the AI brain.</p>
  <p>For that cool TUI (Textual User Interface), <em>I</em> used the amazing <strong>Textual</strong> library. It makes building sophisticated terminal applications way easier than it has any right to be. It's like a framework for making your terminal apps look and feel like modern graphical apps, but with text! <strong>Rich</strong> (which Textual uses) helps with the nice colors and formatting you see in the prompts and messages. <em>I</em> wanted the interface to be helpful, not just functional.</p>
  <p>And for that handy "Copy" command? <em>I</em> brought in <strong>Pyperclip</strong>, a neat little library that handles clipboard operations across different operating systems. It just makes copying the generated command seamless.</p>
</section>

<section id="try-it-out">
  <h2 class="text-3xl font-bold text-gray-100 mb-4">Get 1q Running - It Takes Just a Minute!</h2>
  <p>Ready to give 1q a whirl? <em>I</em> made the installation super simple using pip.</p>
  <ol class="list-decimal list-inside mb-4">
    <li><strong>Install it via pip:</strong> Open your terminal and run:
      <br/><code>pip install oneq</code>
      <br/>(Or even better, use <code>pipx install oneq</code> for a clean installation!)
    </li>
    <li><strong>Set up your API Key:</strong> 1q needs a Google Gemini API key. Get one free from <a href="https://aistudio.google.com/app/apikey" class="text-teal-500 underline">Google AI Studio</a>. You can either:
        <ul>
          <li>Set the <code>GEMINI_API_KEY</code> environment variable (recommended).</li>
          <li>Or just run <code>1q</code> once without the key set, and <em>I</em> built a little setup TUI to guide you through saving it.</li>
        </ul>
    </li>
    <li><strong>Make Your First Query!:</strong> Try asking it something!
      <br/><code>1q how to check disk space on linux</code>
      <br/>or
      <br/><code>1q generate a python function to reverse a string</code>
    </li>
  </ol>
  <p>Boom! You should get a command or snippet back. Interact with it using the prompts (inline or TUI). <em>I</em> hope you find it as helpful as <em>I</em> do!</p>
</section>
